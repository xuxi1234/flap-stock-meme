# 蝴蝶股票：固定20轮批量空投

这是一项固定任务：4000个不重复随机地址，每地址计划及验收到账7枚，共28000枚。每轮200地址合并成一笔发放交易；授权另计一笔。工具费0，不向批量合约转入BNB。随机地址可能无人控制，不能代表4000名用户或真实社区增长。

## 运行步骤

1. 打开 [20轮空投运行页面](https://github.com/xuxi1234/flap-stock-meme/actions/workflows/airdrop-20x200.yml)。
2. 点击右侧 **Run workflow（运行工作流）**，分支保持 **main**。
3. 默认“只读检查”不读取私钥、不签名、不广播，可下载 `plan.csv` 查看完整4000地址。
4. 要发送时，选择 **执行空投**，勾选确认框，再点绿色 **Run workflow**。只需手动启动一次，脚本顺序完成授权和20轮交易。
5. 运行结束下载 `airdrop-results-…`：`results.csv` 含每地址实际到账和交易哈希，`journal.json` 为恢复记录，`summary.txt` 为中文摘要。

脚本只能由仓库main分支的手动工作流执行。PR、push以及只读检查不注入钱包私钥。不要在输入框、代码或日志填写私钥。

## 中断与重复运行

- 原名单由固定公开任务标识确定，任何重跑都不会再随机生成另一组地址。
- 每笔签名的哈希在广播前写入独立分支 `automation/airdrop-20x200-ledger`，保存成功才广播；分支不触发网站部署。
- 重跑逐笔验证回执和每地址实际到账，再检查链上批次完成标记。已完成轮次跳过；20轮全部完成后，再运行也不会多发。
- 未确认交易沿用同一nonce和同一签名哈希，不自动提价或换nonce。未知状态停止，不盲目新发。
- 回滚交易也累计Gas，并停止自动重试。实际到账不等于7枚、节点分歧、额外钱包交易、预算不足都会停止。保留记录，提供运行链接以便核对。
- 不要删除检查点、修改任务标识、并行使用该钱包发送其他交易。即使检查点丢失，nonce和链上完成标记也会阻止从头重发。
- 本任务与原Mint工作流共用GitHub并发锁。完成后只撤销本批量合约仍剩余的授权，不操作其他授权。

## 验证与边界

`node --test scripts/mint-acceptance/airdrop-tests.mjs` 执行离线行为测试。
`AIRDROP_MODE=check node scripts/mint-acceptance/airdrop-run.mjs` 进行本地只读主网检查，不需要私钥；本地无GitHub检查点时仅检查首次执行条件。

只读检查验证余额、历史预算、合约代码和下一步调用。未授权之前无法直接在主网模拟后续transferFrom；后续每笔发送前仍会在两个RPC模拟，并逐地址核对成功回执。这不是对未来Gas、代币税率或未来交易成功的保证。
