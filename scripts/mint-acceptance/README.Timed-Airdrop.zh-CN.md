# 蝴蝶股票定时空投：30次，每次200地址，每地址0.1枚

新任务使用6000个不重复随机地址，排除上一项20轮任务的4000地址。每次20枚，共600枚。随机地址不代表真实用户，代币可能无人掌握私钥、无法找回。

## 已完成第一轮后，继续剩余29次

旧cron在首次成功后长时间没有触发，其后的一次触发又在回执读取阶段失败。现已移除自动cron，改为一次手动启动的29个串行GitHub jobs。每个job等待距上一轮确认至少20分钟后只处理一轮。单job最多40分钟，整体可以跨越6小时，不依赖cron准时触发。

1. 打开 [继续剩余轮次入口](https://github.com/xuxi1234/flap-stock-meme/actions/workflows/airdrop-timed-continue.yml)。
2. 点击 **Run workflow**，分支保持 **main**。
3. 选择 **继续剩余轮次**，勾选确认，再点绿色 **Run workflow**。
4. 同一运行中的29个步骤依次执行，保留原名单、任务ID、已发第一轮和已用Gas。达到30轮后其余队列步骤只检查退出，不发币。
5. 中断后从同一入口继续即可；已确认轮次不会重复。**Cancel workflow会停止本次队列的后续步骤**，但不能撤回已经广播的交易。

如果第一轮已发出超过20分钟，继续后可立即发第二轮，其余28轮各至少间隔20分钟；理想情况下还需至少9小时20分钟，GitHub排队或网络请求可能延长时间。延迟后不会集中补发。

只读RPC请求最多重试3次；重试范围不包含签名、发送交易、保存检查点或预算校验。读取持续失败时给出安全的中文阶段提示，不输出带密钥的URL。发生错误会停止排队的后续步骤；再次继续仍核对原哈希和费用。

**此入口只续跑已经完成至少一轮的原任务，不能另建名单或重置预算。** 私钥沿用现有Secret，不需要重新填写。

## 查看结果、暂停和恢复

- [公开恢复记录](https://github.com/xuxi1234/flap-stock-meme/blob/automation/airdrop-30x200-timed-ledger/journal.json) 在首次启动后建立，包含每笔哈希、nonce、费用和确认时间，不包含私钥或原始签名。
- 每次实际执行的Artifacts提供 `results.csv`（已核实到账地址、0.1枚实际到账和哈希）、`plan.csv`（完整6000名单）、`journal.json`、`summary.txt`。
- 点击本次续跑工作流的 **Cancel workflow** 可取消后续队列；广播过的交易仍需按原哈希核对。
- 继续时选 **继续剩余轮次**并确认。未满20分钟时会等待，不会提前发送。
- 原cron已移除，取消本次队列后不会由cron自动重启；原单轮入口仍可用于只读检查或将任务标记为暂停。
- 任何一笔成功后断网都会先按原哈希核对，已发轮次不重复。失败交易Gas仍计入，并暂停。未知nonce、字节码变化、余额不足、实际到账不是0.1枚或累计费用超限时停止发送。
- 不要删除状态分支，也不要并行用该钱包做其他交易。原Mint、20轮空投和新定时任务共用并发锁；记录外交易会触发停止。

## 开发验证

`node --test scripts/mint-acceptance/timed-airdrop-tests.mjs` 验证6000地址、精确600枚、延迟不补发、间隔、31笔授权加发放、响应丢失恢复、防重复、预算以及权限。

`TIMED_OPERATION=check AIRDROP_REPORT_DIR=/tmp/timed-check node scripts/mint-acceptance/timed-airdrop-main.mjs` 只读核对首次条件，不读取钱包私钥。本地不连接GitHub时无法恢复远程已有任务，线上检查会读取其持久记录。

已有测试不保证未来节点可用性或未来Gas；若20分钟后没有新轮次，查看最新GitHub运行的中文报告。GitHub仓库若为私有仓库，Actions运行时间可能计入账户配额，与链上Gas分开。
