# 7031 地址钱包确认空投

[打开页面](https://gupiao.sh/airdrop-7031/index.html) · [GitHub Actions入口](https://github.com/xuxi1234/flap-stock-meme/actions/workflows/airdrop7031-wallet.yml)

1. 在安装钱包扩展的浏览器或钱包内置浏览器打开页面。
2. 连接 0x74a7D3198905C3b4BA53574C2DffEF3aa4e569aA，切换 BSC。
3. 停止同一钱包其他自动发送任务；核对当前批次并勾选确认。
4. 如额度不足，点击授权并在钱包确认。必要时先归零旧授权，再重新授权本任务剩余数量。
5. 点击本批发送，在钱包核对费用并本人确认。页面等待至少3个区块确认。
6. 上一批确认满60分钟后，由本人再次点击发送下一批。无需重复授权足够的额度。
7. 更换设备时，可粘贴上一批交易哈希恢复计时。导出并保存交易记录。

固定名单：快照区块123329990，7031个唯一地址。
36批：前35批各200地址，末批31地址。每地址转出0.7777枚，共5468.0087枚。
代币：0x4b112e1ed0c0cb332d2b39e5dae3bba882f67777；实际到账受税费影响。
分发合约：0x369890cb7a233be14d33fd4265b26afadce00bc0。
Gas累计预算不设上限，gas估算加20%余量，价格由钱包确定。

GitHub工作流只测试和提供页面入口；不会在后台运行36小时或自动转币。
每笔交易由浏览器钱包确认，代码不读取任何私钥或GitHub钱包Secret。
间隔由页面依据链上回执区块时间执行，不是合约级时间锁。
链上completed记录用于防止本任务批次重复；同一名单在其他任务中发过不代表本任务已完成。
网络或钱包返回结果不明确时，页面停止并要求核对交易哈希，不会盲目重发。
本页面与旧5557地址任务独立，未修改或停止旧任务。

验证：固定名单SHA256、全部7031地址和转账数额的ABI解码、36批次标识、上一批回执与3区块确认、
60分钟到期时间、失败/伪造/重组回执拒绝、错误钱包拒绝、连接和刷新不会发交易、
本人点击仅发一笔且保留待确认哈希。使用模拟钱包测试，未执行真实转账。
