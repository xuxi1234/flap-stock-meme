# 蝴蝶股票空投工具预览

入口 `/?view=airdrop`。这是配置与清单预览，未接入代币授权、钱包交易签名或链上发送。

- 随机地址：设置每地址数量和 1–200 个地址，使用浏览器随机数生成模拟地址。模拟地址没有已确认接收人，不代表真实用户增长。
- 指定地址：粘贴或导入 UTF-8 CSV/TXT（最多 2 MB / 2000 个地址），每行一个地址或包含一个地址列。重复、无效、零地址与有多个地址的行都会阻止生成。
- 私募分配：固定 151 个 0.2 BNB 名额、360 个 0.05 BNB 名额，权重为 4:1，共 964 份。仅填写总量即可计算；一旦填入名单，必须同时满足两档人数。跨档重复保留两档权益。
- 使用 BigInt 按代币最小单位分配，0.2 档严格为 0.05 档四倍，余量单独显示，不超额分发。
- 合约预填自用户截图，链上名称/代码/精度实时读取。读取失败明确标注采用 18 位预览精度；不能据此宣称合约身份或发币成功。
- 钱包仅请求连接并读取 BSC 链 ID、余额。不读私钥、不调用 approve / sendTransaction / personal_sign。
- 名单仅在内存处理，不上传后端。CSV 都标注“仅预览，未发送”，不包含伪造哈希。
- 未部署工具合约，不显示虚构费用、授权额度、Gas 或交易成功结果。

验证：`npm run build`；`npx vitest run src/airdrop/math.test.ts`。
