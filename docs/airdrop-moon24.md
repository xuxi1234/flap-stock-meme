# 蝴蝶中秋 CSV 空投

原 CSV 22535 个唯一地址，排除黑洞 0x000000000000000000000000000000000000dead 和发送钱包自身，固定 22533 个地址。其余地址保留原顺序，包括合约地址；不按历史空投名单过滤。

每地址转出 1 枚，税费由代币合约决定，不补发。113 批：112 × 200 + 133。相邻批次链上时间至少 900 秒。首批到末批理论最少 28 小时，另加运行与确认时间。

独立 campaign ID 和 automation/airdrop-moon24-ledger 检查点。沿用付费 RPC Secret、钱包 Secret 和共享执行锁。广播前保存交易哈希，恢复时双节点核对回执、批次和交易序号。累计 Gas 不设上限。

在 Actions 的 airdrop-moon24.yml 选择 main → 启动或继续空投 → 勾选确认。默认只读；push 只做测试与只读核验。不重跑旧版本或删除 ledger。转账开始后不要让该钱包同时执行其他交易。
