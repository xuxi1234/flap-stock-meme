# 蝴蝶股票（FLAP STOCK）Meme 官网设计规格

## 项目定位

蝴蝶股票是一个独立的纯 Meme 项目。官网负责讲述品牌故事、承载社区入口和展示准确的代币资料；它不是股票交易平台、证券产品、发币平台或收益工具。

- 正式名称：蝴蝶股票
- 英文名称：FLAP STOCK
- 代币符号：FLAP
- 核心口号：不要预测风口，成为扇动翅膀的人。
- 核心叙事：一次转发、一次创作或一次社区互动，都可能形成 Meme 世界的蝴蝶效应。

## 第一版范围

第一版交付高完成度、响应式的单页官网与预售参与功能，包括：

1. 首屏品牌区：Logo、主口号、简介和社区/购买入口。
2. 蝴蝶效应：用三张卡片解释“一只蝴蝶、一次扇动、一场风暴”。
3. Meme 行情面板：只显示明确的娱乐指标，不伪造实时价格或交易量。
4. How to Flap：准备钱包、通过官方链接兑换、参与社区传播。
5. Meme Gallery：首批内置品牌二创卡片，不建设上传后台。
6. Token 信息：名称、符号、链、合约、供应量与用途；未知信息显示 COMING SOON。
7. Meme 路线图：FLAP、FLY、BUTTERFLY EFFECT 三阶段。
8. 页脚：社区链接、合约地址和风险声明。
9. 预售：连接钱包后通过独立智能合约固定支付 0.05 BNB，并展示倒计时、剩余名额和参与状态。

第一版不包含实时行情后端、数据库、CMS、代币部署、自动发放 FLAP 或收益承诺。

## 预售智能合约

- 网络：BNB Smart Chain 主网（chainId 56）。
- 单地址金额：严格等于 0.05 BNB。
- 单地址次数：一个链上地址最多成功参与一次。
- 参与上限：10,000 个地址，对应理论募集上限 500 BNB。
- 初始截止时间：北京时间 2026-09-09 23:59:59（UTC+8），Unix 时间戳 1788969599。
- 管理员：0xbE37AB912De351B9312FA593C9f99e3279FDB0a2。
- 收款地址：0x59389BDb944a4d8D4747b373b665a781d8DCD420。
- 每次成功参与后，合约立即把 0.05 BNB 转入固定收款地址。
- 管理员可以修改截止时间、暂停和恢复预售。
- 管理员不能修改固定参与金额、参与上限或收款地址。
- 达到 10,000 个地址或到达截止时间后拒绝新的参与。
- 合约记录参与状态、参与序号，并发出包含地址、金额和时间的事件。
- 合约不自动发放 FLAP；项目方后续根据链上参与记录手动发送。
- 合约不提供退款功能；网站必须在交易确认前明确提示这一点。
- “一个地址一次”不等于“一个自然人一次”，系统不能阻止同一人使用多个钱包。
- 使用 Checks-Effects-Interactions、重入保护、暂停机制和自定义错误降低执行风险。

## 视觉与交互

- 主色：#F3BA2F 与 #FFD21E。
- 背景：#050505；卡片：#111111；正文灰：#A7A7A7。
- 风格：黑金像素、赛博股票终端、金色霓虹与少量故障艺术。
- 使用用户提供的蝴蝶股票 Logo 作为核心品牌资产。
- Logo 翅膀约每四秒轻微扇动；首屏 K 线只在加载时绘制一次。
- 按钮悬停使用像素位移和金色辉光；滚动出现少量蝴蝶粒子。
- 手机端减少粒子并支持 prefers-reduced-motion。
- 不自动播放音乐，不使用重型 WebGL，不复制币安商标或完整 UI。

## 内容规则

- 主要文案使用简体中文，关键标题可搭配英文。
- 允许荒诞 Meme 文案，例如“没有基本面，只有蝴蝶面”。
- 不使用“稳赚、保本、必涨、财富自由”等收益承诺。
- 页面必须明确写明：FLAP 是社区 Meme 代币，不是真实股票、证券或投资产品。
- 代币合约地址、预售合约地址、链、供应量、X、Telegram 和购买链接集中存放在单一配置文件中。
- 未提供的链接不可伪造，界面显示 COMING SOON 或禁用状态。

## 技术架构

- 使用 React、TypeScript 和 Vite 构建静态单页网站。
- 使用 Solidity 与 Foundry 开发、测试和部署预售合约；前端使用 viem 读取状态并提交交易。
- 内容区拆分为独立组件，项目配置与展示逻辑分离。
- 动画优先使用 CSS；只在必要处加入轻量 JavaScript。
- 使用 Vitest 与 Testing Library 验证核心渲染、配置状态和复制交互。
- 使用 Playwright 验证桌面端与移动端关键路径和无横向溢出。
- 生产构建由 Vercel 托管，不需要服务器端运行时；链上状态直接从 BSC RPC 读取。

## 独立性与发布

- GitHub 新建独立仓库 `flap-stock-meme`。
- Vercel 新建独立项目 `flap-stock-meme`。
- 不复用或修改 BNBX、70X 的仓库、项目、环境变量、域名、钱包或合约。
- 第一阶段发布 Vercel 独立预览/生产链接；自定义域名不在本次范围内。
- Git 提交使用中性项目身份，不把旧项目名称或旧邮箱写入站点元数据。

## 验收标准

1. 桌面端和主流手机宽度均可完整浏览，无横向滚动。
2. 首页清楚显示“蝴蝶股票”“FLAP STOCK”和“FLAP”。
3. 图片、字体和首屏动画不会阻塞页面主要内容。
4. 减少动态效果的系统设置能够关闭非必要动画。
5. 未配置链上或社区数据时不显示虚假信息。
6. 合约地址配置后可以一键复制并显示成功反馈。
7. 单元测试、端到端测试和生产构建全部通过。
8. GitHub 与 Vercel 均为独立新项目，线上链接可以公开访问。
9. 合约测试覆盖错误金额、重复参与、暂停、截止、满额、权限、收款失败和重入场景。
10. 未配置预售合约地址时，网站不可构造或发送交易，并明确显示尚未开放。
