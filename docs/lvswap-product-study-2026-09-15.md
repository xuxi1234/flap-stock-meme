# LVSwap 全站研究与蝴蝶 Swap 改造清单

日期：2026-09-15。研究方式：在 LVSwap 实际打开页面、切换选项、查询公开代币合约；对照蝴蝶 Swap 分支 feat/swap-fees-referrals（d4c88dc）代码与预览。本文记录研究结果和待实现要求，不代表这些新增功能已经在蝴蝶 Swap 上线。

## 1. 结论

LVSwap 的价值在于完整交易流程：顶部统一导航和搜索，把行情、即时兑换、限价、跟单、流动性、成交探索和钱包连接串起来。蝴蝶 Swap 上一版完成了行情与兑换的双栏布局、邀请面板和收费合约代码，但还没有完成这套产品结构。

下一版应先补统一导航、全站搜索和真实的 Pancake V2 流动性操作，再补成交探索、钱包体验和更多协议。限价与跟单需要独立执行系统，不能通过增加两个标签页宣称支持。

### 搜索实测

在“关于”页面打开顶部搜索。输入“蝴蝶股票”后，本次观察未见匹配行；改为完整合约 0x4b112e1ed0c0cb332d2b39e5dae3bba882f67777 后，出现名称及缩略合约，点击进入 BNB → 蝴蝶股票交易页。因此不能断言 LVSwap 对任意名称都有全网搜索能力。

蝴蝶版应优先支持已收录资产的名称、符号和合约搜索；未收录代币按完整地址读取链上元数据。未知资产明确显示来源，不能把“查到合约”当成安全认证。

### 协议覆盖

兑换页菜单实际列出：PancakeV2、PancakeV3、PancakeV4-alpha、FstSwap、FOURMEME、FLAPSH、ERC-314。流动性页实际仅观察到 PancakeV2 和 FstSwap。不能由兑换菜单推断 V3/V4 流动性管理也已实现。

蝴蝶股票兑换页显示了买卖税、放弃权限、LP 锁定及合约持仓等信息。这些是 LVSwap 的界面标注，本次未核验其来源、计算范围及准确性。

### 限价与跟单的执行含义

限价页提示 BNB 需要先封装为 WBNB。显示空订单列表，只能确认页面结构，不能确认订单撮合、部分成交和取消在链上的实际效果。

跟单说明声称：仅 BSC，目标买入后尝试跟买；使用钱包中的 USDT/WBNB；单次授权固定为 2,000 USDT 或 5 WBNB，覆盖旧额度；金额为单次投入，设置需保存。实际打开空白目标行查看字段后已删除，未保存目标，未授权任何代币。蝴蝶版不应照搬固定的大额授权，应设计可理解的额度、撤销入口、执行上限和停用行为。

钱包研究仅到 WalletConnect 二维码选择页，未连接钱包。资产、邀请及私钥钱包标签来自用户提供的截图，当前会话未验证其登录后操作或收益结算。

## 3. 蝴蝶版产品结构

建议顶部采用“交易 / 流动性 / 探索 / 关于”，保留蝴蝶品牌。官网、美股内容作为清楚的返回入口，不挤占核心交易导航。搜索、网络、钱包在所有页面保持一致。

交易对写入可分享 URL；切换添加/移除时保留合法交易对；将 BNB 归一化为 WBNB 判断同币，拒绝 BNB/WBNB 作为同一 V2 池的两侧。未连接的钱包余额显示未知，不显示为已经查证的零余额。

| 顺序 | 改造内容 | 可核对的完成标准 |
| --- | --- | --- |
| 1 | 统一导航、全站搜索、关于及收费说明 | 所有入口可访问；刷新及返回不丢失页面；按合约搜索识别资产；未知资产有来源提示；手机可操作 |
| 2 | Pancake V2 添加/移除流动性 | 从链上读储备、LP 余额、总供应；双币比例准确；授权对象正确；最小金额和截止时间生效；交易回执后更新仓位 |
| 3 | 探索成交及排行 | 定义平台成交或指定池的统计范围；真实交易哈希；按地址去重人数；标明窗口、来源和更新时间；失败时不伪造数据 |
| 4 | 钱包与邀请中心 | 移动端 WalletConnect；明确账户/网络；链上邀请绑定及逐资产收益；切换账户取消旧请求状态 |
| 5 | 扩大兑换协议覆盖 | 每种协议有独立报价及交易适配、地址核验、模拟与失败处理；先落实需求相关的 Flap/Four.meme，再扩展其他协议 |
| 6 | 限价及跟单 | 明确执行者和资金授权；订单可取消、过期；重试不重复成交；跟单有额度、去重、停用和可追溯记录 |

第一阶段设计保留蝴蝶身份，不复制 LVSwap 的 Logo 和完整文案。可学习浅色背景、卡片分区、紧凑表单和持续可见的导航。移动端优先显示正在操作的交易/LP 表单，次要信息折叠。

## 4. 数据与合约边界

付费 RPC 适合读取链状态、合约、日志和报价，但并不自动提供热门排行、全部持仓者或按小时统计的成交人数。需要按明确范围索引 Swap 等事件，处理去重、链重组、确认数与断点续查；统计缓存与即时交易报价分开。RPC 密钥仅放服务端环境变量，不进入前端包、公开仓库或邀请 URL。GitHub 中存在付费 RPC 配置，不等于网站部署环境已完成配置。

V2 流动性直接集成官方 Router 接口：代币之间与含 BNB 的方法分别处理；LP 授权与普通代币授权区分；滑点和截止时间传入合约。带转账税代币必须单独模拟和验证到账结果。官方文档提供添加、移除及部分支持转账税的方法，不能据此认定所有税币都兼容。

参考：[PancakeSwap Router V2 文档](https://developer.pancakeswap.finance/contracts/v2/router-v2)；[官方外围合约仓库](https://github.com/pancakeswap/pancake-swap-periphery)。引用或复用代码时保留对应许可和来源。

MEV 防护仅在确实接入相应提交路径时显示启用，并明确提交失败的处理方式。监控数据必须标明来源和更新时间，不将“已弃权”或“锁池”展示为安全保证。
