    创建税收代币

    打开 flap.sh，点「创建代币」→ 选「创建税收代币」。

  2. 02

    启用 Vault

    填好名称、符号等基础信息后，在「选择 VAULT」里勾选「启用 Vault」。

  3. 03

    浏览金库工厂

    点「+ 浏览」，进入税收金库列表。

  4. 04

    选未上架模板

    选第一项「未上架的税收模板」，把本页对应金库的工厂地址粘贴进去。

  5. 05

    按说明填写并确认

    页面会按工厂吐出配置项。对照本页「怎么填」写完，确认就能发射。

小白怎么填

选一个金库，按下面「怎么填」一步步抄。看不懂的词，可展开下方词典。

这个金库干啥的

选金库 → 看怎么填 → 复制工厂

公平 Mint · BNB

先募 BNB（每份固定 0.01，目标 0–16），满额后一笔上蝴蝶发射；可挂税金库。参与者按份手动领币；发射前可退款。仅 BNB。

怎么填（照着抄）

流程：创建 Mint 金库 → 用户按份 Mint（0.01 BNB/份）→ 满额一笔发射 → 详情页领币。 目标 0–16 BNB；目标为 0 时跳过 Mint，创建者带首买 BNB 发射。 部署合约后把工厂地址写入 flapMintConfig.js。

站内部署去看这张卡

发射前再核一遍工厂地址和「怎么填」。

这几个词是啥意思点开看白话解释
工厂地址
卡片上的「工厂」，粘到 Flap「未上架的税收模板」。
营销 / 社区钱包
收税地址。多数必填，别填 0x000…。
触发间隔
回购 / 销毁多久跑一次。秒或分钟，以「怎么填」为准。
每次回购金额
单次花掉的 BNB（如 0.01）。别和间隔填反。
外币 / 变异币
双发或变异类填已发射代币地址；发射后一般改不了。
分成比例 / bps
基点写法，如 1000 = 10%。按「怎么填」里的数写。
